# 管理員權限與驗證安全檢視

## 已確認與已強化控制

管理型使用者帳號程序已統一使用後端 `adminProcedure`，不再僅依賴前端按鈕或程序內重複判斷。所有建立帳號、重設密碼、啟用／停用與角色變更均由管理員角色強制保護。

本機帳密採用 bcrypt 成本因子 12 雜湊，不保存明文密碼。新建與重設密碼要求至少 12 字元，且包含大寫英文字母、小寫英文字母與數字。帳號名稱限制為英數字、點、底線及連字號，減少輸入歧義。

每位使用者新增 `sessionVersion`。密碼重設、帳號啟停或角色變更均會遞增版本；受保護請求會驗證 JWT 版本與資料庫版本一致。本機帳號遭停用、重設密碼或調整角色後，既有登入憑證將被撤銷。管理程序同時防止管理員停用自身、降級自身或移除最後一位有效管理員。

敏感帳號操作會寫入 `user_account_audit_logs`，記錄操作人、目標使用者、操作類型與不含密碼雜湊的前後安全狀態。外部登入帳號不可被誤當成本機帳密帳號重設密碼。

## 仍需營運層處理的風險

本機登入目前尚未接入跨節點、持久化的登入失敗限流或多因素驗證；因此公開部署時仍應在反向代理／身分提供者層配置登入節流、IP 防護與監控。使用者資料與部分分析讀取程序因現有系統使用情境仍可公開讀取；若系統需要多租戶或機密製程資料隔離，應在下一階段將讀取程序改為受保護程序並加入產線資料範圍授權。
