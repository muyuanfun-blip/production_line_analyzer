# iPhone 組裝示範線（訓練資料）

本示範線用於驗證生產工站分析系統的 VSM、平衡分析、戰情監控與配置模擬功能。流程依一般消費電子組裝概念建構，**不代表 Apple 的實際、專有或機密製程**。

| 項目 | 設定 |
|---|---|
| 產線 ID | `99001` |
| 產線名稱 | iPhone 組裝示範線（訓練資料） |
| VSM ID | `99001` |
| 產品族 | 智慧型手機旗艦機種 |
| 需求節拍 | 60 秒／件 |
| 每班需求 | 420 件 |
| 可用工時 | 25,200 秒／班 |
| 工站數 | 15 |
| VSM 節點 | 19（含供應商、WIP、客戶節點） |
| 物流／資訊流 | 18 條物流、3 條資訊流 |

流程涵蓋來料 IQC、子組件準備、主裝配、互連、顯示密封、韌體校正、功能與 RF 測試、最終檢驗、包裝及出貨。範例特別標示主裝配前與測試前 WIP、品質關卡、可用率、批量及搬運距離，方便用於資料品質、瓶頸與物流分析。

使用者登入後可開啟：

```text
/lines/99001/vsm
/lines/99001/monitoring
/lines/99001/balance
```
